# The_Survival_Game
This is a 3D survival shooter game developed in Unity where the player must survive against enemies
using FPS shooting mechanics. Through this project, I learned how first-person movement, shooting
systems, enemy interaction, and real-time gameplay mechanics work together in game development.

What I Worked On
• Built first-person movement and camera controls
• Developed shooting and enemy interaction mechanics
• Added player health and survival systems
• Worked on game physics and combat logic
• Improved understanding of 3D gameplay systems in Unity
