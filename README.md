# FPS Survival Game

3D Survival Shooter • Unity • C#

Game Overview

A 3D survival shooter developed in Unity where the player survives against enemies using first-person shooting mechanics. The project explores movement, camera, shooting, enemy interaction and health.

Core Gameplay Loop

Explore → Detect Enemy → Aim / Shoot → Survive → Continue

Game Development
Designed a survival-focused combat loop.
Considered how movement, combat and enemy interaction work together.
Focused on moment-to-moment player interaction.
Programming / Implementation
Built first-person movement and camera controls.
Developed shooting and enemy interaction mechanics.
Added player health and survival systems.
Worked on game physics and combat logic.
Development Challenge

How do multiple real-time systems combine into one coherent survival experience?

What I Learned

Connecting movement, camera, combat, health and enemy interaction into a playable 3D system.
